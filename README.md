# Computer Vision Course

Topic-by-topic notebooks following my university CV course syllabus.
For each topic: study the course material + a reference repo on that topic, then build my own notebook applying it.

## Topics (in order)
1. Introduction to Computer Vision
2. Image Formation & 2D Transformations
3. OpenCV Image Basics (color spaces, geometric ops)
4. Human Vision and Cameras
5. Thresholding & Blurring
6. Morphological Operations
7. Image Histograms
8. Feature Detection and Matching
9. Feature Detection (Edge & Corner Detection)
10. Image Segmentation (incl. U-Net)
11. Feature Detection (Shape, Object, and Face Detection)
12. Object Detection-2 (R-CNN family through Faster R-CNN)

Folders are created as each topic is reached, not pre-built.
